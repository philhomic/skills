# 百度网盘目录整理：中文使用说明

这个技能可以把**你自己百度网盘中某个文件夹的目录结构**整理成两份文件：

- **TXT**：纯文字目录树，适合复制、检索、存档。
- **HTML**：用浏览器查看，支持搜索、排序、按文件类型筛选、展开和收起目录。

整个过程只读取文件夹和文件名称，**不会下载正文，也不会移动、删除、重命名或修改你的网盘原文件**。导出结果是目录清单，不包含课程、视频、PDF 等文件本身。

本文以 Windows 为例；需要你自己登录百度网盘，技能不会提供或共享任何账号。

## 一、安装技能

### 已收到独立技能 ZIP

1. 解压 ZIP，找到名为 `baidu-directory-export` 的文件夹。
2. 将整个文件夹放入你的 Codex 技能目录。Windows 默认位置是：

   ```text
   %USERPROFILE%\.codex\skills\
   ```

   可将上面一行粘贴到资源管理器地址栏。若没有 `skills` 文件夹，可自行创建。如果你设置过 `CODEX_HOME`，则使用该目录下面的 `skills`。
3. 安装后的结构应是：

   ```text
   .codex/
   └── skills/
       └── baidu-directory-export/
           ├── SKILL.md
           ├── README.md
           ├── agents/
           ├── assets/
           ├── references/
           └── scripts/
   ```

   注意不要多套一层同名文件夹，`SKILL.md` 应直接位于 `baidu-directory-export` 下。
4. 新建一个 Codex 对话，在技能选择列表中查找“百度网盘目录整理”，或输入 `$baidu-directory-export`。若暂未显示，重新打开 Codex 后再试。

### 从 GitHub 仓库取得

打开 [philhomic/skills](https://github.com/philhomic/skills)，点击 **Code → Download ZIP**，解压后只把其中的 `baidu-directory-export` 文件夹复制到上述技能目录。无需安装仓库里的其他技能。

## 二、首次使用前需要什么

| 项目 | 用途 | 准备方法 |
| --- | --- | --- |
| Codex | 调用技能、准备命令和核验结果 | 使用你现有的 Codex |
| Python 3.10 或更新版本 | 解析目录、生成 TXT 和 HTML | 从 [Python 官网](https://www.python.org/downloads/windows/) 安装；安装时启用添加到 PATH |
| BaiduPCS-Go | 只读取得网盘目录树 | 从 [项目 Releases](https://github.com/qjfoidnh/BaiduPCS-Go/releases) 下载适合电脑架构的 Windows 压缩包并解压 |
| 百度网盘网页账号 | 读取你有权访问的个人网盘目录 | 在自己的浏览器中登录 |

通常的 Intel/AMD 64 位 Windows 电脑选择 `windows-x64`；ARM 电脑选择 `windows-arm64`。可在 Windows“设置 → 系统 → 关于”中查看系统类型。

技能 ZIP **不包含** Python 或 BaiduPCS-Go，也不包含任何 Cookie 或登录配置。你可以直接告诉 Codex“请帮我检查并准备依赖”，由它检查本机已有工具，并记录客户端的实际路径。

## 三、告诉 Codex 要整理哪个目录

推荐直接发送：

> 使用 $baidu-directory-export，整理我百度网盘里的“/学习资料/数学课程”，导出 TXT 和可搜索、排序、筛选的 HTML。请打开登录向导窗口，让我登录自己的账号。原文件不要动，结果保存在桌面的一个新文件夹中。

可以指定两种输入：

1. **网盘里的完整路径**，例如 `/学习资料/数学课程`。这是网盘路径，不是电脑上的 `C:\...` 路径。
2. **打开目标文件夹后的浏览器地址**，例如 `https://pan.baidu.com/disk/main#/index?category=all&path=...`，直接复制完整地址即可，不必手工解码中文。

不支持将 `https://pan.baidu.com/s/...` 的公开分享链接直接作为目标。请先确认资料已经在你自己的网盘中，并使用自己的目录路径；本技能不会自动转存。

每次指定一个目录，包含它下面所有层级的文件夹及文件。输出文件夹应使用新名称，避免覆盖旧结果。

## 四、在弹出的窗口中登录自己的账号

Codex 应打开一个独立的 PowerShell 登录向导。窗口会显示目标目录、输出位置和具体步骤，不需要你自己拼接命令。

### 为什么不直接输入账号和密码

BaiduPCS-Go 的旧账号密码登录方式长期不维护，可能返回 `50052：系统繁忙`。本技能使用**先在浏览器正常登录，再将 Cookie 输入到本机向导**的方式。二维码、短信等网页登录验证由你自己完成。

### Cookie 获取步骤

1. 在 Chrome 或 Edge 打开 [百度网盘](https://pan.baidu.com)，登录**你自己的账号**。
2. 按 **F12** 打开开发者工具，切换到 **Network（网络）**。
3. 刷新页面，让网络请求列表出现内容。
4. 在列表中选择名称以 **`list?`** 开头的请求；如果找不到，可选择 **Doc（文档）**，找到 **`main`** 或 **`main?...`** 请求。
5. 在右侧选择 **Headers（标头）**，确认 **Request URL** 属于 `https://pan.baidu.com/`。
6. 向下找到 **Request Headers（请求标头）→ Cookie**，复制 Cookie 后面的完整值，**不要包括 `Cookie:` 标签**。
7. 回到 PowerShell 向导，在隐藏输入提示处粘贴，然后按回车。显示星号或看不到明文属于正常情况。
8. 登录后，检查窗口中显示的账号是否是你自己的；正确时输入 **Y** 并回车，向导开始导出。账号不对就取消。

**不要复制 Response Headers 中的 Set-Cookie。不要把 Cookie 发到聊天、邮件、GitHub 或公开截图里。** Cookie 相当于登录凭据。

不同使用者每次都使用自己的登录配置。技能会为任务准备单独目录，但同一 Windows 用户下的不同文件夹并不等于权限隔离：多人使用同一电脑时，建议分别使用自己的 Windows 账户。

## 五、等待导出并查看结果

目录较大时需要等待几分钟。看到绿色的“导出完成”及保存路径后，再关闭向导窗口。不要在扫描尚未结束时关闭窗口。

输出目录包含：

| 文件 | 用途 |
| --- | --- |
| `directory.txt` | 可用记事本打开的完整目录树 |
| `directory.html` | 双击后在浏览器中查看的交互目录 |
| `tree-raw.log` | 客户端原始目录输出，排查问题时使用 |
| `stderr.log` | 客户端错误日志；正常时通常为空 |

向导只有在目录结构解析通过后才生成最终文件；发生错误时请保留日志并把**错误文字**告诉 Codex，不要把 Cookie 或登录配置文件发出来。程序不能确认空目录时也会停止，避免把登录失败误报为空目录。

导出完成可对 Codex 说：

> 已导出成功，请核对 TXT 和 HTML 的条目数，并测试搜索、排序、筛选功能。

目录是扫描期间的快照；以后新增或移除资料，需要再导出一次。清单本身不会实时更新。

## 六、HTML 功能怎么用

| 功能 | 用法 |
| --- | --- |
| 搜索 | 输入文件名或路径关键词；多个关键词用空格隔开，例如 `二年级 讲义`，同时满足才显示 |
| 类型筛选 | 选择 PDF、MP4 等实际存在的扩展名，或选择“仅文件夹” |
| 组合条件 | 搜索和类型筛选可同时使用；匹配项会连同上级文件夹一起显示 |
| 排序 | 选择原始顺序、名称升序或降序；只调整同级条目的显示，名称排序时文件夹优先，并按数字自然排序 |
| 展开/收起 | 点击文件夹旁的小三角；也可点击“全部展开”或“全部收起” |
| 重置 | 清空搜索和筛选，恢复原始顺序并收起目录 |

HTML 内含所需数据和代码，不依赖外部字体、脚本服务或网盘登录。关闭网络后仍可查看。它只是目录清单，点击名称不会下载或打开网盘文件。分享 TXT 或 HTML 会透露其中的文件名称和路径，请只发给合适的人。

## 七、结束登录或换一个人使用

本次登录配置保存在向导显示的独立目录中，**不会打包进技能或导出文件**。它会在任务后保留，直到你主动退出或清理。

需要退出时，可告诉 Codex：

> 请帮我退出这次任务使用的 BaiduPCS-Go 本地账号，使用本次独立配置目录，不要动其他任务或网盘文件。

下一位使用者应新建自己的任务配置，重新登录自己的浏览器账号，不能直接复用上一位使用者的配置目录。不要把配置目录、Cookie 或客户端登录文件复制给其他人。

## 八、常见问题

| 情况 | 处理方法 |
| --- | --- |
| 看不到登录窗口 | 告诉 Codex“请直接打开可见的 PowerShell 登录向导”；若运行环境不能弹窗，再请它给出填好路径的完整命令 |
| 系统提示禁止执行脚本 | 将错误文字发给 Codex；在组织管理电脑上遵循管理员要求，不要盲目修改全局执行策略 |
| 找不到 `python` 或客户端 | 请 Codex 检查依赖和实际安装路径；命令中的程序与脚本应使用完整路径 |
| 错误 `50052` | 不再重复旧密码登录，按本说明改用网页登录 Cookie |
| 错误 `-6`、提示重新登录 | 可能是 Cookie 失效或读取了不同配置；检查本次配置目录，再按需重新登录 |
| 自己登录成功，Codex 却看不到账号 | 让向导在你已登录的同一环境完成导出，不要反复把 Cookie 发送给助手 |
| 目标不存在或没有权限 | 核对当前账号以及网盘中的完整目录路径 |
| 提示输出目录已存在 | 换一个新的输出文件夹，不覆盖旧清单 |
| 搜索不到预期内容 | 点击重置，再输入较短的关键词；多个词表示同时满足，类型筛选也会影响结果 |

## 九、已有 TXT，能否只生成 HTML

可以，不需要重新登录或扫描网盘。将此前由本技能导出的 TXT 路径交给 Codex：

> 使用 $baidu-directory-export，把这个 directory.txt 转成带搜索、排序和筛选的 HTML，保存到一个新文件夹。

支持本技能生成的 TXT 和已知格式的 BaiduPCS-Go 树形日志，不保证支持任意手工排版的文本目录。
