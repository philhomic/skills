# 百度网盘目录导出

面向普通使用者的安装、登录、目录选择和导出步骤见 [中文使用说明](README.md)。用户首次使用或请求操作说明时优先提供该文档。

## 范围与产物

默认生成 UTF-8 `directory.txt` 和独立离线 `directory.html`；HTML 支持名称/路径多关键词搜索、扩展名/仅文件夹筛选、同级自然排序、展开/收起和重置。只操作目录元信息，不下载正文，不调用上传、删除、移动、转存或分享命令。BaiduPCS-Go 的 `export` 是另一种功能，本技能使用 `tree`。

依赖 Python 3.10+；在线导出另需 BaiduPCS-Go。技能不携带客户端二进制、账号、Cookie、真实目录数据或登录配置。客户端从 [项目 Releases](https://github.com/qjfoidnh/BaiduPCS-Go/releases) 获取与系统匹配的版本，放在技能外部工具目录；不要把本机安装路径写成跨用户默认值。

## 工作流程

1. 从请求取得目标路径/个人网盘网页链接、输出目录。`/disk/main` URL 只是账号内导航地址，需要该账号登录；公开 `/s/` 分享链接不适用，不要擅自转存。若缺少目标目录，再询问使用者。
2. 每次任务创建独立、绝对路径的登录配置目录，例如用户自己的本地应用数据目录下 `baidu-directory-export/sessions/<随机任务ID>`。与输出目录和技能目录分开。不要默认沿用其他人的账号或全局 BaiduPCS-Go 配置。仅在同一使用者明确要求续用同一任务时复用该配置。
3. 需要登录时，阅读 [登录说明](references/login.md)。Windows 优先启动可见的 `scripts/start-export.ps1` 向导窗口，传入客户端、配置目录、目标目录和输出目录；向导显示详细 Cookie 获取说明、隐藏输入、账号确认，并在确认后自动导出。不要只给使用者一串命令。仅在无法打开交互窗口时提供命令作为备选。若本次运行环境要求可见窗口的明确授权，先取得授权。底层 `scripts/login.ps1` 可用于单独登录测试。不向聊天索要 Cookie，不读取或打印配置文件内容。不同人分别使用自己的任务配置。
4. 登录和导出必须使用同一个 `BAIDUPCS_GO_CONFIG_DIR`。运行以下导出命令，将所有占位符替换为实际绝对路径：

```text
python <技能目录>/scripts/directory_export.py export --tool <客户端绝对路径> --config-dir <本次登录配置目录> --target <网盘路径或URL> --output <新的输出目录>
```

5. 检查脚本成功状态及条目数，再提供 TXT/HTML 链接。脚本解析失败、登录失败或空输出未能确认时不声明完整导出；保留诊断日志，避免反复登录和无限重试。目录导出是扫描时快照，不保证与同时变更的网盘具有事务一致性。
6. 如代理环境仍看不到用户终端登录状态，让用户在登录的终端执行同一条绝对路径导出命令。不要继续要求重新提供 Cookie。生成后核验数据/输出，区别实际验证与未执行的浏览器测试。

## 已有 TXT 离线转换

```text
python <技能目录>/scripts/directory_export.py convert --input <directory.txt绝对路径> --output <新的输出目录>
```

支持本技能及此前本流程的目录 TXT（标题、网盘路径、导出时间、空行、树形正文）。原始 `tree` 日志可通过 `--target /目标目录` 转换。不猜测未知树形格式或补造缺失条目；保留原始顺序和名称。默认拒绝覆盖已有产物。

## 完整性与账号边界

- 不凭进程退出码 0 判断成功：客户端可能在 stdout 报错并返回 0。严格检查每个树行、父子层级及重复路径；未知行必须失败。
- 不设置深度限制，完整遍历指定目录。对没有树行的输出保守报错，人工核实空目录后再处理。
- 名称以文本渲染并转义 HTML/内嵌 JSON，不能将网盘文件名当成代码。
- 共享技能仅打包本目录内的代码、模板和说明。输出清单也可能含私人文件名，不自动上传。
- 登录凭据在本次配置目录中持久保存。任务结束告知路径；用户需要结束会话时，使用相同配置目录执行客户端 `logout`。不把配置、Cookie 或真实导出结果打包进技能。
